# Prompt CLAUDE.md

Um prompt de cinco fases que atualiza o `CLAUDE.md` do seu projeto para o Claude Code dividir as tarefas em três níveis de raciocínio, usar o modelo certo para cada nível e parar para pedir a sua aprovação antes de subir de nível.

## Como usar

1. Abra a pasta do seu projeto no Claude Code.
2. Copie o bloco "O prompt" do arquivo [PROMPT-CLAUDE-MD.md](PROMPT-CLAUDE-MD.md), cole na conversa e envie.
3. Revise cada rascunho antes de aprovar. Ele não salva nada sem o seu "pode".

## Avisos

O Claude Code não troca de modelo sozinho no meio da conversa. A trava faz o Claude parar e avisar, e você libera. Este prompt não garante uma redução fixa de consumo. Não coloque senhas nem chaves de acesso no `CLAUDE.md`.
